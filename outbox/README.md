# Outbox

Drafts for a human to review and send. Nothing here has been submitted, and
nothing here should be submitted without reading it first.

Each draft states three things and claims nothing beyond them: what the feed
is, how entries are sourced, and how often it updates. No pitch, no adjectives,
no promises about roadmap. The maintainers being written to are busy and
receive a lot of this; the shortest version that lets them evaluate the offer
is the polite one.

Check before sending:
- The entry and indicator counts match the current release.
- The contribution being offered is still the one the code needs — these were
  written against a clone at a point in time, and upstream moves.
- The links resolve.
